== Attachment options

*-c, --creator* <value>::
    Filter by creator.
+
.Attachments created by user:
 bite bugzilla attachment search -c user

*-d, --description* <value>::
    Filter by description.

*-f, --filename* <value>[,...]::
    Filter by file name.

*-i, --id* <value>[,...]::
	Filter by bug ID.

*-m, --mime* <type>::
    Filter by MIME type.
+
.Text-based attachments:
 bite bugzilla attachment search -m '=* text/.+'

*-s, --size* <value>::
    Filter by size.

*-c, --created* <value>::
    Filter by creation time.

*-u, --updated* <value>::
    Filter by update time.

*-o, --is-obsolete* [<bool>]::
	Filter by obsolete status.

*-p, --is-patch* [<bool>]::
	Filter by patch status.

*-P, --is-private* [<bool>]::
    Filter by private status.
